## C. 자주 나는 오류와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| `claude`를 찾을 수 없음 | 설치 후 터미널을 새로 열지 않음 | 터미널 새로 열기 → 그래도 안 되면 재시작 |
| `'&&' is not a valid statement separator` | PowerShell에서 CMD용 명령 | `irm https://claude.ai/install.ps1 \| iex` 사용 |
| `'irm' is not recognized` | CMD에서 PowerShell용 명령 | CMD용 설치 명령 사용 |
| 로그인 후 사용 불가 | 무료 요금제 | Pro 이상 요금제 |
| 사용량 한도에 걸림 | 요금제 한도 초과 | `/usage`로 확인, 잠시 기다리거나 `/rate-limit-options` |
| 엉뚱한 폴더에 파일이 생김 | 다른 폴더에서 `claude` 실행 | `/exit` → `cd 프로젝트폴더` → `claude` |
| Claude가 규칙을 안 지킴 | 규칙이 애매하거나 너무 김 | 구체적으로, 200줄 이하로. `/context`로 읽혔는지 확인 |
| 대화가 느리고 앞 내용을 잊음 | 대화 공간이 가득 참 | `/compact` 또는 `/clear` |
| 자동 모드에서 작업이 막힘 | 안전 검사기가 위험하다고 판단 | `/permissions`의 최근 거부 목록 확인, 필요하면 수동 모드로 |
| `git push`가 403 오류 | Claude에게 저장소 권한 없음 | Claude GitHub App에서 저장소 허용 + claude.ai/connect-github 재연결 |
| `/rewind` 후에도 파일이 그대로 | 터미널 명령으로 바뀐 파일 | Git으로 되돌리기 ("마지막 커밋 상태로 되돌려 줘") |

그래도 안 되면: `claude doctor` 실행 → 공식 문서 https://code.claude.com/docs/en/troubleshoot-install

## D. 용어 사전

| 용어 | 뜻 |
|---|---|
| **터미널** | 글자로 컴퓨터에 명령하는 창 |
| **프롬프트** | ① 터미널에서 명령을 기다리는 표시 ② Claude에게 보내는 요청 문장 |
| **CLI** | 터미널에서 쓰는 프로그램 (Command Line Interface) |
| **컨텍스트** | Claude가 지금 기억하고 있는 대화와 파일 내용. 크기에 한계가 있음 |
| **토큰** | Claude가 글을 처리하는 단위. 사용량과 비용의 기준 |
| **모델** | Claude의 "두뇌" 종류. 강한 모델일수록 어려운 일을 잘하지만 사용량이 큼 |
| **권한 모드** | Claude가 묻지 않고 할 수 있는 일의 범위 |
| **CLAUDE.md** | Claude가 매번 읽는 프로젝트 안내문 |
| **저장소 (Repository)** | Git이 관리하는 프로젝트 폴더 |
| **커밋** | 지금 상태를 저장한 세이브 포인트 |
| **브랜치** | 원본을 건드리지 않고 따로 작업하는 갈래 |
| **푸시** | 커밋을 GitHub에 올리기 |
| **PR (Pull Request)** | 브랜치 작업을 원본에 합쳐 달라는 요청 |
| **API** | 프로그램끼리 정보를 주고받는 창구 |
| **API 키** | API를 쓰기 위한 비밀 열쇠. 절대 공개하면 안 됨 |
| **`.env`** | 비밀 정보를 따로 보관하는 파일 |
| **`.gitignore`** | Git에 올리지 않을 파일 목록 |
| **MCP** | Claude Code에 외부 서비스를 연결하는 표준 방법 |
| **Skill** | 나만의 `/명령어`로 등록한 작업 순서 |
| **서브에이전트** | 특정 역할을 맡은 보조 Claude |
| **Hook** | 정해진 순간에 항상 자동 실행되는 명령 |

## E. CLAUDE.md 템플릿

복사해서 `CLAUDE.md`로 저장한 뒤 `( )` 부분을 채우세요.

```markdown
# CLAUDE.md

## 프로젝트 개요
- 목적: (무엇을 만드는지 한두 줄)
- 사용자: (누가 쓰는지)

## 기술 스택
- 언어/프레임워크: (예: HTML, CSS, JavaScript)
- 라이브러리: (쓰지 않음 / 사용하는 것)

## 자주 쓰는 명령어
- 실행: (예: index.html을 브라우저로 열기 / npm run dev)
- 테스트: (예: npm test)

## 규칙
- 한 번에 하나의 기능만 작게 만들고, 확인한 뒤 다음으로 넘어간다.
- 새 라이브러리를 추가하기 전에 이유를 말하고 허락을 받는다.
- API 키와 비밀번호는 코드에 쓰지 않고 .env에 둔다.
- 기능이 완성될 때마다 커밋한다. 커밋 메시지는 한국어로.

## 커뮤니케이션
- 설명과 답변은 한국어로 한다.
- 코딩 초보도 이해할 수 있게 쉽게 설명한다.
- 작업이 끝나면 무엇을 바꿨는지, 내가 확인할 것이 무엇인지 짧게 정리한다.
```

## F. 자주 묻는 질문 (FAQ)

**Q. 코딩을 전혀 몰라도 쓸 수 있나요?**
네. 이 가이드의 미니 프로젝트는 코드를 직접 쓰지 않고 말로만 진행합니다. 다만 결과를 확인하고 "왜 이렇게 했어?"라고 물어보며 조금씩 이해해 가면 훨씬 잘 쓰게 됩니다.

**Q. 비용은 얼마나 드나요?**
Claude 유료 요금제(Pro, Max 등)에 포함되어 있고, 요금제마다 사용 한도가 다릅니다. 지금 사용량은 `/usage`로 확인할 수 있습니다. 최신 요금은 claude.com/pricing 을 확인하세요.

**Q. 내 코드가 AI 학습에 쓰이나요?**
계정 종류와 설정에 따라 다릅니다. Pro·Max 요금제는 `/privacy-settings`에서 설정을 확인하고 바꿀 수 있습니다. 자세한 내용은 Anthropic 개인정보 처리방침을 확인하세요.

**Q. Claude가 만든 코드는 믿어도 되나요?**
대체로 잘 동작하지만 실수할 수 있습니다. 직접 실행해 보고, `/diff`로 변경을 확인하고, 중요한 코드는 `/code-review`로 점검하세요.

**Q. 인터넷이 없으면 쓸 수 없나요?**
네, 인터넷 연결이 필요합니다.

**Q. 한국어로 요청해도 되나요?**
네. 한국어로 요청해도 잘 이해합니다. CLAUDE.md에 "답변은 한국어로"를 적어 두면 답변도 항상 한국어로 받습니다.

**Q. 실수로 중요한 파일을 망쳤어요!**
1. `/rewind`로 되돌리기 (Claude가 편집한 파일)
2. 안 되면 "마지막 커밋 상태로 되돌려 줘" (Git)
3. 앞으로는 큰 작업 전에 항상 커밋하세요.
