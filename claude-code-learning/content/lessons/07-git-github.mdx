# 7. Git·GitHub와 함께 쓰기

## 📌 이 페이지에서 배울 것
- Git이 왜 필요한지와 꼭 알아야 할 용어 5개
- Claude에게 말로 커밋·브랜치·PR을 시키는 법
- GitHub와 Claude를 연결하고, 웹(클라우드)에서 작업하는 법

⏱ 예상 시간: 35분

---

## 7-1. Git이 왜 필요할까?

Git은 **게임의 세이브 포인트**입니다. 저장해 두면 언제든 그 시점으로 돌아갈 수 있습니다.

6장에서 배운 `/rewind`는 편리하지만 한계가 있었습니다. 터미널 명령으로 지운 파일은 되돌리지 못하고, 약 30일 뒤 기록이 지워집니다. **Git 커밋은 직접 지우지 않는 한 영원히 남고, 무엇이든 되돌릴 수 있습니다.**

| | `/rewind` | Git 커밋 |
|---|---|---|
| 되돌릴 수 있는 것 | Claude가 편집한 파일 | 저장한 시점의 모든 파일 |
| 기간 | 약 30일 | 영구 |
| 다른 사람과 공유 | 불가 | GitHub로 공유 가능 |

---

## 7-2. 꼭 알아야 할 용어 5개

| 용어 | 쉬운 뜻 | 비유 |
|---|---|---|
| **저장소 (Repository)** | Git이 관리하는 프로젝트 폴더 | 세이브 파일이 들어 있는 게임 폴더 |
| **커밋 (Commit)** | 지금 상태를 저장한 것 | 세이브 포인트 |
| **브랜치 (Branch)** | 원본을 건드리지 않고 따로 작업하는 갈래 | 평행 세계 |
| **푸시 (Push)** | 내 커밋을 GitHub에 올리기 | 클라우드 백업 |
| **PR (Pull Request)** | "내 브랜치 작업을 원본에 합쳐 주세요"라는 요청 | 결재 올리기 |

> 💡 **GitHub**는 Git 저장소를 인터넷에 올려 두는 서비스입니다. Git은 프로그램, GitHub는 웹사이트입니다.

---

## 7-3. 처음 한 번만: Git 설치와 설정

**① Git 설치**
- Windows: 2장에서 설치한 **Git for Windows**에 포함되어 있습니다.
- macOS: 터미널에서 `git --version`을 입력하면 설치 안내가 나옵니다.
- 확인: `git --version`을 입력해서 버전 번호가 나오면 됩니다.

**② 내 이름과 이메일 등록** (커밋에 기록됩니다)
```bash
git config --global user.name "홍길동"
git config --global user.email "내GitHub이메일@example.com"
```

**③ GitHub 계정 만들기**: https://github.com 에서 가입합니다.

---

## 7-4. Claude에게 말로 시키기

Git 명령어를 외울 필요는 없습니다. Claude에게 말로 하면 됩니다.

| 하고 싶은 것 | Claude에게 이렇게 |
|---|---|
| Git 시작 | "이 폴더를 Git 저장소로 만들어 줘" |
| 저장 | "지금까지 바꾼 내용을 커밋해 줘" |
| 상태 확인 | "아직 커밋 안 한 변경 사항 보여 줘" |
| 기록 보기 | "최근 커밋 5개를 쉽게 설명해 줘" |
| 되돌리기 | "마지막 커밋 상태로 되돌려 줘" |
| 따로 작업 | "dark-mode라는 브랜치를 만들고 거기서 작업해 줘" |
| GitHub에 올리기 | "GitHub에 푸시해 줘" |
| 합치기 요청 | "이 브랜치로 PR 만들어 줘" |

### 💻 따라 하기
```text
이 폴더를 Git 저장소로 만들고, .gitignore에 .env를 넣은 다음, 첫 커밋을 해 줘. 커밋 메시지는 한국어로.
```

### 좋은 습관
- **기능 하나가 완성될 때마다 커밋**: 작은 세이브 포인트가 많을수록 안전합니다.
- **큰 작업 전에 커밋**: "작업 시작 전에 지금 상태를 커밋해 줘"
- **원본(main)에서 바로 작업하지 않기**: 새 기능은 브랜치에서

> ⚠️ "강제로 푸시해 줘(force push)", "기록을 지워 줘" 같은 요청은 되돌릴 수 없는 손실을 만들 수 있습니다. 왜 필요한지 먼저 물어보세요.

## 7-5. GitHub에 처음 올리기

**① GitHub에서 빈 저장소 만들기**
1. https://github.com/new 접속
2. Repository name 입력 (예: `my-first-project`)
3. Public(공개) 또는 Private(비공개) 선택 → **Create repository**

**② 내 PC의 저장소와 연결하고 올리기**
```text
https://github.com/내아이디/my-first-project 저장소에 연결하고 푸시해 줘.
```

처음 푸시할 때 GitHub 로그인 창이 뜨면 로그인합니다.

> 💡 **GitHub CLI(`gh`)**를 설치해 두면 Claude가 PR 만들기 같은 GitHub 작업을 더 쉽게 합니다. https://cli.github.com 에서 설치한 뒤 `gh auth login`으로 로그인하세요.

## 7-6. PR(Pull Request) 흐름

```
main (원본)  ──●────────────────●── (합쳐짐)
                \              /
dark-mode        ●──●──●──→ PR
                (작업·커밋)
```

1. "dark-mode 브랜치를 만들어서 다크 모드 기능을 만들어 줘"
2. "커밋하고 푸시해 줘"
3. "PR 만들어 줘. 무엇을 바꿨는지 설명도 써 줘"
4. GitHub에서 PR을 열어 변경 내용을 확인하고 **Merge** 버튼으로 합칩니다.

> 💡 PR 전에 `/code-review`로 버그를 점검하면 더 안전합니다.

## 7-7. 웹(클라우드)에서 Claude Code 쓰기

**claude.ai/code** 에서는 내 PC에 설치하지 않고도 Claude Code를 쓸 수 있습니다. 폰에서도 됩니다.

| | 내 PC (터미널) | 웹 (클라우드) |
|---|---|---|
| 작업 장소 | 내 컴퓨터 폴더 | 클라우드 컴퓨터에 복사된 GitHub 저장소 |
| 결과 저장 | 내 컴퓨터에 바로 | **GitHub에 푸시해야 남음** |
| 필요한 것 | 설치 | GitHub 연결 |

### 연결하기
1. **GitHub 연결**: claude.ai/code 에서 안내에 따라 GitHub 계정을 연결합니다. 터미널에서 `gh`를 쓰고 있다면 `/web-setup`으로도 연결할 수 있습니다.
2. **Claude GitHub App 설치**: https://github.com/apps/claude 에서 설치하고, Claude가 접근할 저장소를 고릅니다. 내 PC 터미널에서 `/install-github-app`을 실행해도 안내를 받을 수 있습니다.
3. 새 세션을 시작할 때 작업할 저장소를 고릅니다.

### 실제 사례: 푸시가 403 오류로 실패할 때
```
fatal: unable to access 'https://github.com/...': The requested URL returned error: 403
```
**원인**: Claude에게 그 저장소에 쓸 권한이 없습니다.

**해결**:
1. https://github.com/apps/claude/installations/select_target 에서 내 계정 선택
2. **Repository access**에서 해당 저장소를 포함하거나 **All repositories** 선택 → **Save**
3. https://claude.ai/connect-github 에서 GitHub 다시 연결
4. Claude에게 "다시 푸시해 줘"

## ✅ 확인하기
- [ ] `git --version`으로 Git 설치를 확인했다
- [ ] `user.name`과 `user.email`을 설정했다
- [ ] Claude에게 시켜서 첫 커밋을 했다
- [ ] GitHub에 저장소를 만들고 푸시했다
- [ ] 브랜치를 만들어 작업하고 PR을 만들어 봤다

## ⚠️ 자주 하는 실수
- **커밋 없이 오래 작업하기**: 중간에 망가지면 돌아갈 곳이 없습니다.
- **`.env`를 커밋하기**: 한 번 GitHub에 올라간 비밀 정보는 지워도 기록에 남습니다. 키를 새로 발급받아야 합니다.
- **웹 세션에서 푸시를 잊기**: 클라우드 세션은 끝나면 사라집니다. 꼭 푸시하세요.

   - (가) 푸시  (나) 브랜치  (다) PR
