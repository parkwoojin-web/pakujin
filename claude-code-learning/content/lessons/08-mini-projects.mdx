# 8. 따라 하는 미니 프로젝트

## 📌 이 페이지에서 배울 것
- 지금까지 배운 기능을 모아 실제로 동작하는 앱 3개 만들기
- 계획 → 작은 단계 → 확인 → 커밋의 흐름 익히기

⏱ 예상 시간: 프로젝트 1 (30분) · 프로젝트 2 (1시간) · 프로젝트 3 (2시간)

> 🛠 준비: 프로젝트마다 **새 폴더**를 만들고 그 안에서 `claude`를 실행하세요.
> ```bash
> mkdir profile-page
> cd profile-page
> claude
> ```

### 모든 프로젝트에 공통인 흐름

```
① /init 또는 CLAUDE.md 작성 → ② /plan으로 계획 → ③ 한 단계씩 요청
→ ④ 브라우저로 확인 → ⑤ 커밋 → ③으로 돌아가기
```

---

## ⭐ 프로젝트 1. 자기소개 웹페이지 (30분)

### 🎯 목표
내 이름, 소개, 좋아하는 것 3가지, 연락처 버튼이 있는 한 장짜리 웹페이지

### 💬 단계별 요청
**1단계: 규칙 정하기**
```text
CLAUDE.md를 만들어 줘. 내용: HTML 파일 하나로 된 자기소개 페이지. 외부 라이브러리는 쓰지 않는다. 설명은 한국어로 쉽게.
```

**2단계: 기본 페이지**
```text
index.html을 만들어 줘. 맨 위에 내 이름 "홍길동"과 한 줄 소개 "AI로 코딩을 배우는 중입니다"를 크게 보여 줘.
```

**3단계: 내용 추가**
```text
소개 아래에 "좋아하는 것" 제목과 함께 등산, 커피, 고양이를 카드 3개로 나란히 보여 줘.
```

**4단계: 꾸미기**
```text
전체 배경은 연한 베이지색, 카드는 흰색에 둥근 모서리와 옅은 그림자를 넣어 줘. 폰 화면에서는 카드가 세로로 쌓이게 해 줘.
```

**5단계: 버튼**
```text
맨 아래에 "이메일 보내기" 버튼을 넣고, 누르면 hong@example.com으로 메일 쓰기 창이 열리게 해 줘.
```

**6단계: 저장**
```text
Git 저장소로 만들고 커밋해 줘.
```

### ✅ 확인 체크리스트
- [ ] 브라우저에서 이름, 소개, 카드 3개, 버튼이 모두 보인다
- [ ] 브라우저 창을 좁히면 카드가 세로로 쌓인다
- [ ] 버튼을 누르면 메일 프로그램이 열린다
- [ ] 커밋이 1개 이상 있다

### 🚀 도전 과제
- "다크 모드 전환 버튼을 추가해 줘"
- "내 사진을 넣고 싶어. `me.jpg`를 동그랗게 보여 줘" (사진 파일을 폴더에 넣은 뒤)

## ⭐⭐ 프로젝트 2. 할 일 목록 앱 (1시간)

### 🎯 목표
할 일을 추가하고, 완료 표시하고, 삭제할 수 있으며, **브라우저를 닫았다 열어도 목록이 남는** 앱

### 💬 단계별 요청
**1단계: 계획부터**
```text
/plan 할 일 목록 웹앱을 만들고 싶어. HTML, CSS, JavaScript 파일 3개로 나누고, 라이브러리는 쓰지 마. 기능은 추가, 완료 체크, 삭제, 그리고 새로고침해도 목록이 유지되는 것. 먼저 계획만 보여 줘.
```
계획을 읽고 **Yes, manually approve edits**를 골라 진행합니다.

**2단계: 추가 기능만 먼저**
```text
계획의 첫 단계만 해 줘: 입력창과 "추가" 버튼, 그리고 추가한 할 일이 아래 목록에 나타나는 것까지.
```
➡️ 브라우저에서 직접 할 일을 3개 추가해 보고 확인한 뒤 커밋합니다.

**3단계: 완료와 삭제**
```text
각 할 일 앞에 체크박스를 넣어서, 체크하면 글자에 줄이 그어지게 해 줘. 오른쪽에는 삭제 버튼을 넣어 줘.
```

**4단계: 저장 기능**
```text
새로고침해도 목록이 사라지지 않게 브라우저의 localStorage에 저장해 줘. 어떻게 동작하는지 쉽게 설명도 해 줘.
```

**5단계: 편의 기능**
```text
입력창에서 Enter를 눌러도 추가되게 하고, 빈칸은 추가되지 않게 막아 줘. 맨 위에 "남은 할 일: 3개"처럼 개수도 보여 줘.
```

**6단계: 점검**
```text
/code-review
```
찾은 문제가 있으면 "찾은 문제를 고쳐 줘"라고 요청한 뒤 커밋합니다.

### ✅ 확인 체크리스트
- [ ] 할 일을 추가, 체크, 삭제할 수 있다
- [ ] 새로고침해도 목록이 남아 있다
- [ ] 빈칸은 추가되지 않는다
- [ ] 남은 개수가 정확하다
- [ ] 단계마다 커밋이 있다 (커밋 4개 이상)

### 🚀 도전 과제
- "할 일을 더블클릭하면 내용을 고칠 수 있게 해 줘"
- "전체 / 진행 중 / 완료 필터 버튼을 추가해 줘"

## ⭐⭐⭐ 프로젝트 3. 날씨 앱 + GitHub에 공개 (2시간)

### 🎯 목표
도시 이름을 입력하면 현재 날씨와 3일 예보를 보여 주는 앱을 만들고, **GitHub Pages로 인터넷에 공개**하기

> 💡 날씨 정보는 **Open-Meteo**(https://open-meteo.com)를 씁니다. 가입이나 API 키가 필요 없는 무료 날씨 서비스입니다.

### 💬 단계별 요청
**1단계: 계획**
```text
/plan 도시 이름을 입력하면 현재 기온, 날씨 상태, 3일 예보를 보여 주는 웹앱을 만들고 싶어. Open-Meteo의 지오코딩 API로 도시를 좌표로 바꾸고, 예보 API로 날씨를 가져와. HTML/CSS/JS만 쓰고 라이브러리는 쓰지 마.
```

**2단계: 도시 검색**
```text
첫 단계만 해 줘: 도시 이름을 입력하면 그 도시의 위도와 경도를 화면에 보여 주는 것까지. 한국 도시 이름(예: 부산)도 되게 해 줘.
```

**3단계: 현재 날씨**
```text
찾은 좌표로 현재 기온과 날씨 상태를 가져와서 보여 줘. 날씨 코드는 "맑음", "흐림", "비"처럼 한국어와 이모지로 바꿔 줘.
```

**4단계: 3일 예보**
```text
아래에 3일 예보를 카드로 보여 줘. 날짜, 최고/최저 기온, 날씨 이모지를 넣어 줘.
```

**5단계: 오류 처리**
```text
없는 도시를 입력하거나 인터넷이 끊겼을 때 친절한 안내 문구를 보여 줘. 불러오는 동안에는 "불러오는 중…"을 보여 줘.
```

**6단계: GitHub에 올리기**
```text
Git 저장소로 만들어 커밋하고, GitHub에 weather-app 저장소를 만들어서 푸시해 줘.
```
(GitHub 저장소를 Claude가 만들 수 없으면 7-5처럼 직접 만든 뒤 "이 주소로 푸시해 줘"라고 요청합니다.)

**7단계: 인터넷에 공개 (GitHub Pages)**
1. GitHub의 저장소 페이지 → **Settings** → **Pages**
2. **Source**: Deploy from a branch, **Branch**: `main` / `(root)` → **Save**
3. 1~2분 뒤 `https://내아이디.github.io/weather-app/` 에서 내 앱을 볼 수 있습니다.

### ✅ 확인 체크리스트
- [ ] "서울", "부산", "Tokyo"를 검색하면 날씨가 나온다
- [ ] 3일 예보 카드가 보인다
- [ ] 없는 도시를 입력하면 안내 문구가 나온다
- [ ] GitHub Pages 주소로 폰에서도 열린다

### 🚀 도전 과제
- "마지막으로 검색한 도시를 기억해서 다음에 열면 바로 보여 줘"
- "현재 위치 버튼을 눌러서 내 위치의 날씨를 보여 줘"
