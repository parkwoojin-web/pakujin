# 2. 설치와 첫 실행

## 📌 이 페이지에서 배울 것
- 내 컴퓨터에 Claude Code 설치하기
- 로그인하고 처음 실행하기
- Claude Code로 첫 웹페이지 만들기

⏱ 예상 시간: 20분

---

## 2-1. 설치하기

터미널을 열고, **내 운영체제에 맞는 명령 한 줄**을 복사해서 붙여 넣은 뒤 Enter를 누르세요.

### 🪟 Windows

먼저 내가 어떤 터미널에 있는지 확인합니다.
- 줄 앞에 **`PS`**가 보이면 → **PowerShell** (예: `PS C:\Users\홍길동>`)
- `PS` 없이 `C:\`로 시작하면 → **CMD**

**PowerShell이라면:**
```powershell
irm https://claude.ai/install.ps1 | iex
```

**CMD라면:**
```batch
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

> 💡 관리자 권한으로 실행할 필요는 없습니다.

**(권장) Git for Windows 설치하기**
Claude Code는 Git for Windows가 없어도 동작하지만, 설치하면 더 많은 기능을 쓸 수 있고 7장(Git·GitHub)에서도 필요합니다.
1. https://git-scm.com/downloads/win 에서 내려받습니다.
2. 설치 화면에서는 **기본값 그대로 Next**를 계속 누르면 됩니다.

### 🍎 macOS / 🐧 Linux
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

### 설치가 조용해도 정상입니다
설치 명령은 내려받는 동안 **진행 상황을 보여 주지 않습니다.** 끝날 때까지 기다려 주세요.

> 다른 설치 방법도 있습니다. macOS의 Homebrew(`brew install --cask claude-code`)나 Windows의 WinGet(`winget install Anthropic.ClaudeCode`)으로 설치하면 **자동 업데이트가 되지 않으므로**, 초보자에게는 위의 기본 방법을 추천합니다.

---

## 2-2. 설치 확인하기

**터미널 창을 닫고 새로 연 다음** 입력합니다.
```bash
claude --version
```

이렇게 버전 번호가 나오면 성공입니다.
```
2.1.xxx (Claude Code)
```

더 자세히 점검하려면:
```bash
claude doctor
```
설치 상태와 설정 문제를 확인하고, 문제가 있으면 해결 방법을 알려 줍니다.

---

## 2-3. 처음 실행하고 로그인하기

**① 연습용 폴더로 이동합니다** (1장에서 만든 폴더)
```bash
cd my-first-project
```

**② Claude Code를 실행합니다**
```bash
claude
```

**③ 처음 실행하면 몇 가지를 물어봅니다**
- **화면 색상(테마)**: 화살표 키로 고르고 Enter
- **로그인**: 브라우저가 열리면 Claude 계정으로 로그인하고 허용을 누릅니다. 끝나면 터미널로 돌아옵니다.
- **이 폴더를 믿을지**: 내가 만든 연습 폴더이므로 허용합니다.

> ⚠️ 모르는 사람에게 받은 폴더에서는 신뢰를 허용하기 전에 한 번 더 생각하세요. Claude Code가 그 폴더의 설정 파일을 따르기 때문입니다.

**④ 입력창이 나타나면 준비 완료!**

---

## 2-4. 첫 화면 둘러보기

> 📷 (스크린샷 자리: Claude Code 첫 화면)

| 부분 | 설명 |
|---|---|
| **입력창** | 여기에 한국어로 요청을 씁니다 |
| **대화 영역** | 내 요청, Claude의 답, Claude가 한 작업이 순서대로 쌓입니다 |
| **권한 요청 창** | Claude가 파일을 만들거나 명령을 실행하기 전에 "해도 될까요?"라고 묻습니다 |

### 화면 아래 상태 표시줄: 권한 모드
입력창 아래에 **지금 권한 모드**가 표시됩니다. 최신 버전은 처음에 보통 이렇게 시작합니다.

```
⏵⏵ auto mode on
```

**자동 모드(auto mode)**에서는 Claude가 매번 허락을 묻지 않고 작업합니다. 대신 별도의 안전 검사기가 위험해 보이는 작업을 막아 줍니다.

> 💡 **처음 배울 때는 수동 모드를 추천합니다.** `Shift + Tab`을 한 번 누르면 `⏸ manual mode on`으로 바뀝니다. 수동 모드에서는 Claude가 파일을 만들거나 명령을 실행하기 전에 매번 물어보므로, **무엇을 하는지 보면서 배울 수 있습니다.** 권한 모드는 6장에서 자세히 배웁니다.

### 권한 요청 창 읽는 법 (수동 모드)
수동 모드에서는 Claude가 파일을 바꾸거나 명령을 실행하기 전에 허락을 구합니다. 대략 이런 선택지가 나옵니다.

| 선택 | 뜻 |
|---|---|
| **Yes** | 이번 한 번만 허용 |
| **Yes, and don't ask again …** | 이런 종류의 작업은 앞으로 묻지 않고 허용 |
| **No** | 거절. Claude가 멈추고 내 다음 말을 기다립니다 |

> 💡 **Yes**나 **No**에 커서를 두고 `Tab`을 누르면 짧은 메모를 덧붙일 수 있습니다. 예: No + "파일 이름은 index.html로 해 줘"

## 2-5. ✅ 첫 성공 미션: 나의 첫 웹페이지

입력창에 아래 문장을 그대로 입력해 보세요.

```text
hello.html 파일을 만들어 줘. 가운데에 "안녕하세요, 저는 ○○입니다"라고 크게 쓰고, 배경은 하늘색으로 해 줘.
```

**일어나는 일** (수동 모드 기준)
1. Claude가 무엇을 할지 설명합니다.
2. `hello.html` 파일을 만들어도 되는지 묻습니다. → **Yes**
3. 파일이 만들어집니다.

자동 모드라면 묻지 않고 바로 파일을 만듭니다.

**결과 확인하기**
- 파일 탐색기(macOS는 Finder)에서 `my-first-project` 폴더를 열고 `hello.html`을 **더블클릭**하면 브라우저에 페이지가 열립니다.
- 또는 Claude에게 "방금 만든 파일 브라우저로 열어 줘"라고 요청해도 됩니다.

**한 단계 더**: 바꾸고 싶은 점을 말로 요청해 보세요.
```text
글자 아래에 오늘 날짜를 작게 보여 주고, 글자에 그림자를 넣어 줘.
```
브라우저에서 새로고침(`F5`, macOS는 `Cmd + R`)하면 바뀐 결과가 보입니다.

🎉 **축하합니다!** 코드를 한 줄도 직접 쓰지 않고 웹페이지를 만들었습니다.

## 2-6. 끝내기와 다시 시작하기

| 하고 싶은 것 | 방법 |
|---|---|
| Claude Code 끝내기 | `/exit` 입력, 또는 `Ctrl + C`를 두 번 |
| 다시 시작 | 같은 폴더에서 `claude` |
| 지난 대화 이어 하기 | `claude` 실행 후 `/resume` |
| Claude가 작업 중일 때 멈추기 | `Esc` |

---

## ✅ 확인하기
- [ ] `claude --version`으로 버전 번호를 확인했다
- [ ] 로그인을 마쳤다
- [ ] `Shift + Tab`으로 수동 모드(`manual mode on`)로 바꿔 봤다
- [ ] `hello.html`을 만들고 브라우저에서 열어 봤다
- [ ] 말로 수정 요청을 해서 페이지를 바꿔 봤다
- [ ] `/exit`로 끝내고 다시 `claude`로 시작해 봤다

## ⚠️ 자주 하는 실수와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| `claude`를 찾을 수 없다고 나옴 (`not recognized`, `command not found`) | 설치 직후 터미널을 새로 열지 않음 | **터미널을 닫고 새로 열기**. 그래도 안 되면 컴퓨터 재시작 |
| `The token '&&' is not a valid statement separator` | PowerShell에서 CMD용 명령을 입력함 | PowerShell용 명령(`irm ... \| iex`)을 사용 |
| `'irm' is not recognized` | CMD에서 PowerShell용 명령을 입력함 | CMD용 명령(`curl ... install.cmd`)을 사용 |
| 로그인했는데 사용할 수 없다고 나옴 | 무료 요금제 | Pro 이상 요금제로 변경 |
| 엉뚱한 폴더에 파일이 생김 | `cd`로 이동하지 않고 `claude`를 실행함 | `/exit` → `cd my-first-project` → `claude` |

그 밖의 문제는 `claude doctor`를 실행하거나, 공식 문제 해결 문서(https://code.claude.com/docs/en/troubleshoot-install)를 확인하세요.
