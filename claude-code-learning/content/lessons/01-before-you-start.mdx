# 1. 시작하기 전에

## 📌 이 페이지에서 배울 것
- Claude Code가 무엇이고, 채팅 Claude와 무엇이 다른지
- Claude Code를 쓰려면 무엇이 필요한지
- 터미널을 열고 기본 명령 3가지를 쓰는 법

⏱ 예상 시간: 15분

---

## 1-1. Claude Code란?

Claude Code는 **내 프로젝트 폴더 안에서 직접 일하는 AI 개발 도우미**입니다.

채팅 Claude에게 "웹페이지 만들어 줘"라고 하면 코드를 **글로 보여 줍니다.** 그 코드를 복사해서 파일로 저장하고 실행하는 일은 내가 해야 합니다.

Claude Code에게 같은 요청을 하면 **파일을 직접 만들고, 실행해 보고, 문제가 있으면 고칩니다.** 나는 결과를 확인하고 승인만 하면 됩니다.

| | 채팅 Claude | Claude Code |
|---|---|---|
| 비유 | 옆에서 조언해 주는 선배 | 내 컴퓨터에 앉아 직접 일하는 동료 |
| 코드 | 글로 보여 줌 | 파일을 직접 만들고 고침 |
| 실행 | 못 함 | 명령을 실행하고 결과를 확인 |
| 에러 | 내가 복사해서 알려 줘야 함 | 스스로 보고 고침 |
| 잘 맞는 일 | 아이디어, 설명, 짧은 코드 | 실제로 돌아가는 프로그램 만들기 |

> 💡 둘 다 같은 Claude입니다. 차이는 **손이 있느냐**입니다. Claude Code는 파일을 읽고 쓰고 명령을 실행할 수 있는 "손"을 가진 Claude입니다.

---

## 1-2. 할 수 있는 것과 못 하는 것

**✅ 잘하는 것**
- 웹페이지, 앱, 간단한 프로그램을 처음부터 만들기
- 이미 있는 코드를 읽고 설명하기
- 에러 원인을 찾아서 고치기
- 여러 파일을 한꺼번에 고치기
- Git 커밋, GitHub에 올리기

**❌ 대신 못 하는 것**
- **무엇을 만들지 정하기**: 아이디어와 요구사항은 내가 정해야 합니다.
- **계정·결제가 필요한 일**: 도메인 구입, 앱스토어 등록, 클라우드 결제
- **비밀번호·API 키 만들기**: 직접 발급받아 알려 줘야 합니다.
- **100% 정확함**: 실수할 수 있으므로 결과는 꼭 직접 확인해야 합니다.

## 1-3. 필요한 것

| 필요한 것 | 설명 |
|---|---|
| **유료 계정** | Claude **Pro, Max, Team, Enterprise** 요금제 또는 **Console(API) 계정**. ⚠️ **무료 요금제로는 쓸 수 없습니다.** |
| **컴퓨터** | Windows 10(1809 이상), macOS 13 이상, 또는 Ubuntu 20.04 이상 등 Linux. 메모리 4GB 이상 |
| **인터넷** | 항상 연결되어 있어야 합니다 |
| **(Windows 권장) Git for Windows** | 없어도 동작하지만, 있으면 더 많은 기능을 쓸 수 있습니다. 2장에서 설치합니다 |

> 💡 예전에는 Node.js가 필요했지만, **지금 권장하는 설치 방법은 Node.js가 필요 없습니다.**

## 1-4. 어디에서 쓸까?

Claude Code는 여러 곳에서 쓸 수 있습니다. 처음에는 **하나만** 고르세요.

| 방식 | 특징 | 추천 대상 |
|---|---|---|
| **터미널 (CLI)** | 가장 기본. 모든 기능 사용 가능 | 이 가이드의 기본 방식 ⭐ |
| **데스크톱 앱** | 터미널 없이 창에서 사용 | 터미널이 정말 부담스러운 분 |
| **VS Code 확장** | 코드 편집기 안에서 사용 | VS Code를 이미 쓰는 분 |
| **웹 (claude.ai/code)** | 설치 없이 브라우저에서. 작업은 클라우드에서 하고 GitHub에 저장 | GitHub를 쓰는 분, 폰에서 쓰고 싶은 분 |

이 가이드는 **터미널 방식**을 기준으로 설명합니다. 다른 방식도 명령어와 사용법은 거의 같습니다.

## 1-5. 터미널 기초 5분

터미널은 **글자로 컴퓨터에 명령하는 창**입니다. 마우스로 폴더를 여는 대신, 글자로 "이 폴더로 가"라고 입력합니다.

### 터미널 여는 법

| 운영체제 | 여는 법 |
|---|---|
| **Windows** | 시작 버튼 → `PowerShell` 검색 → 클릭 |
| **macOS** | `Cmd + Space` → `터미널` 입력 → Enter |
| **Linux** | `Ctrl + Alt + T` |

열리면 이런 줄이 보입니다. 이것을 **프롬프트**라고 하며, "명령을 기다리고 있어요"라는 뜻입니다.

```
PS C:\Users\홍길동>          ← Windows PowerShell
홍길동@MacBook ~ %           ← macOS
```

### 꼭 알아야 할 명령 3가지

**① 지금 위치의 파일 보기**
```bash
ls
```
(Windows CMD에서는 `dir`. PowerShell에서는 `ls`도 됩니다)

**② 새 폴더 만들기**
```bash
mkdir my-first-project
```

**③ 폴더로 이동하기**
```bash
cd my-first-project
```
상위 폴더로 돌아가려면:
```bash
cd ..
```

### 터미널 꿀팁
- **`Tab` 키**: 폴더 이름 앞 글자만 치고 누르면 자동 완성됩니다.
- **`↑` 키**: 방금 입력한 명령을 다시 불러옵니다.
- **붙여넣기**: Windows는 `Ctrl + V` 또는 마우스 오른쪽 클릭, macOS는 `Cmd + V`
- **실행 중인 것 멈추기**: `Ctrl + C`

## 🧠 퀴즈
1. Claude Code가 채팅 Claude와 가장 크게 다른 점은?
   - (가) 더 똑똑한 모델을 쓴다
   - (나) 파일을 직접 만들고 명령을 실행할 수 있다
   - (다) 무료다
2. 폴더 안으로 이동하는 명령은?
   - (가) `ls`  (나) `mkdir`  (다) `cd`

<details>
<summary>정답 보기</summary>

1. (나) — 같은 Claude지만 파일과 명령을 다룰 "손"이 있습니다.
2. (다) — `ls`는 목록 보기, `mkdir`은 폴더 만들기입니다.

</details>
