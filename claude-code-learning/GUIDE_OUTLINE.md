## 1. 시작하기 전에
- Claude Code란? 채팅 Claude와의 차이 (비교표)
- 할 수 있는 것과 못 하는 것
- 필요한 것: 유료 요금제(Pro/Max 등) 또는 API 크레딧, PC, 인터넷
- 쓸 수 있는 곳: 터미널, VS Code, 데스크톱 앱, 웹(claude.ai/code), 모바일
- 터미널 기초 5분: 터미널 여는 법, `cd`, `ls`(Windows `dir`), `mkdir`
- 나에게 맞는 방식 고르기: PC 터미널 vs 웹 클라우드

## 2. 설치와 첫 실행
- 운영체제별 설치 (Windows / macOS / Linux 탭)
- 로그인
- 연습용 폴더 만들고 `claude` 실행
- 첫 화면 구성: 입력창, 상태 표시줄, 권한 요청 창 (스크린샷 필수)
- ✅ 첫 성공 미션: "hello.html 만들어 줘" → 브라우저로 열기
- `/doctor`로 설치 문제 점검

## 3. 기본 사용법
- 질문하기 vs 작업 시키기
- `@파일명`으로 파일 지정
- 권한 요청 창 읽기: 승인 / 거절 / 항상 허용
- `Esc`로 멈추기
- 대화 관리: `/clear`, `/compact`, `/resume`, `/context`
- 모델·생각 깊이: `/model`, `/effort`
- 사용량 확인: `/usage`
- `/powerup`으로 기능 둘러보기

## 4. CLAUDE.md로 규칙 정하기
- CLAUDE.md가 무엇이고 왜 중요한지
- `/init`으로 자동 생성
- 꼭 넣을 항목: 개요, 기술 스택, 명령어, 규칙, 답변 언어
- 적용 범위: `~/.claude/CLAUDE.md`(나 전체) → 프로젝트 → 하위 폴더
- `/memory`로 편집
- 좋은 예 vs 나쁜 예 ("코드 잘 짜줘" vs "npm 대신 pnpm 사용")
- 복사해서 쓰는 템플릿

## 5. 잘 시키는 법 (프롬프트)
- 5원칙: 구체적으로 · 작게 나눠서 · 목표와 조건을 함께 · 예시 주기 · 확인 방법 알려 주기
- 나쁜 요청 vs 좋은 요청 10쌍
- 계획 모드: `Shift+Tab` 또는 `/plan` → 계획 검토 → 승인
- 이미지·스크린샷 붙여 넣어 설명하기
- 에러 메시지를 그대로 붙여 넣어 고치게 하기
- 결과가 마음에 안 들 때 다시 요청하는 법

## 6. 안전하게 쓰기
- 권한 모드: 매번 묻기 / 자동 수정 허용 / 계획 모드
- `/permissions`로 허용·차단 규칙
- 되돌리기: `/rewind`, `Esc` 두 번
- `/diff`로 변경 확인하는 습관
- 비밀 정보: API 키는 `.env`, `.gitignore` 설정
- 위험한 요청 예: 파일 대량 삭제, 모르는 스크립트 실행

## 7. Git·GitHub와 함께 쓰기
- Git이 왜 필요한지 ("게임의 세이브 포인트")
- 용어: 저장소, 커밋, 푸시, 브랜치, PR
- Git 설치와 `user.name` / `user.email` 설정
- 말로 시키기: "커밋해 줘", "브랜치 만들어 줘", "PR 만들어 줘"
- GitHub 연결, Claude GitHub App 설치 (`/install-github-app`)
- 웹(클라우드) 세션 작업 흐름 — 푸시해야 저장된다
- 사례: 푸시 403 오류와 해결 (GitHub App 저장소 접근 허용 + claude.ai/connect-github 재연결)

## 8. 따라 하는 미니 프로젝트
각 프로젝트: 목표 → 단계별 요청 문장 → 예상 결과 → 확인 체크리스트
1. ⭐ 자기소개 웹페이지 (HTML 한 파일, 30분)
2. ⭐⭐ 할 일 목록 앱 (추가·삭제·저장, 1시간)
3. ⭐⭐⭐ 날씨 앱 (Open-Meteo API(키 불필요), GitHub에 올리기, GitHub Pages로 공개, 2시간)

## 9. 한 단계 더 (심화)
기능마다 한 페이지, "이럴 때 쓰세요" 위주
- Skills: 나만의 `/명령어` 만들기
- 서브에이전트
- MCP: 외부 도구 연결
- Hooks: 자동 실행 규칙
- 플러그인
- VS Code, 데스크톱 앱, 모바일에서 쓰기
- `/code-review`, `/security-review`로 코드 검토

## 📎 부록
- **명령어 치트시트**: `/` 명령어를 1~5단계로 나눈 표
- **단축키 모음**: `Esc`, `Shift+Tab`, `@`, `Shift+Enter` 등
- **자주 나는 오류와 해결법**: 설치 실패, 로그인 오류, 권한 거절, 사용량 한도, GitHub 403
- **용어 사전**: 터미널, 프롬프트, 컨텍스트, 토큰, 저장소 등
- **FAQ**: 비용, 코드를 몰라도 되는지, 데이터가 학습에 쓰이는지

## 작성 원칙
1. 최신 정보 확인: 공식 문서로 확인하고 페이지마다 "최종 확인일"을 적는다.
2. Windows 사용자 배려: 설치 단계를 특히 자세히.
3. 스크린샷 먼저, 글은 그다음.
4. 전문 용어는 처음 나올 때 한 줄로 설명하고 용어 사전으로 연결한다.
