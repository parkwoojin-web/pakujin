# 다운로드

| 파일 | 설명 |
|---|---|
| `claude-code-guide.html` | 웹 버전. 내려받아 더블클릭하면 브라우저에서 열립니다. 인터넷 없이도 동작합니다. |
| `claude-code-guide.apk` | Android 앱 (Android 7.0 이상). |

## Android 앱 설치 방법
1. 폰에서 `claude-code-guide.apk`를 내려받습니다.
2. 파일을 누르면 "출처를 알 수 없는 앱" 경고가 나옵니다. **설정**을 눌러 이 브라우저(또는 파일 앱)의 설치를 허용합니다.
3. **설치**를 누릅니다. Play 프로텍트가 확인을 요청하면 **그래도 설치**를 고릅니다.

이 앱은 Play 스토어를 거치지 않고 직접 서명한 앱이라 경고가 나옵니다. 인터넷 권한도 요청하지 않습니다.

## 다시 만들기
`claude-code-learning/` 폴더에서 `npm install && npm run build:apk`를 실행한 뒤 `dist/`의 결과를 이 폴더에 복사합니다.
